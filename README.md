# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas + JavaScript 实现的经典坦克大战（Battle City 风格）网页小游戏，单文件即可运行。

## 玩法

- 控制你的坦克，消灭每一关的 20 辆敌方坦克，并守住己方基地（鹰）。
- 基地被摧毁或生命耗尽则游戏结束。
- 每通过一关进入更难的下一关（共 4 张循环地图）。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 开火 | `空格` / `J` / `回车` |
| 暂停 / 继续 | `P` |
| 静音 | `M` |
| 重新开始 | `R` |

移动端会自动显示触屏摇杆与开火按钮。

## 地图元素

- 🧱 **砖墙**（棕色）：可被子弹摧毁
- ⛓️ **钢墙**（灰色）：普通子弹无法摧毁
- 🌊 **水**（蓝色）：坦克不能通过，子弹可以通过
- 🌿 **草丛**（绿色）：可通行，隐藏坦克
- 🦅 **基地**（鹰）：被击中立即失败

## 道具

消灭敌人有概率掉落：★ 火力升级 · ✹ 手雷 · ⛨ 护盾 · ＋ 加命 · ⏱ 冰冻 · ⛏ 修复基地

## 运行

直接用浏览器打开 `index.html` 即可，无需构建或依赖。

也可以使用任意静态服务器，例如：

```bash
npx serve .
```
